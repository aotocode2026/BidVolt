## 2. 环境变量清单（Secret Manager 注入）

| 变量 | 必填 | 说明 |
|---|---|---|
| `DATABASE_URL` | 是 | `postgresql://bidvolt:***@127.0.0.1:5432/bidvolt`（单容器本机） |
| `APP_DB_PASSWORD` | 是 | 应用数据库账号密码（init 脚本建库用，Secret Manager 注入） |
| `BIDVOLT_INTERNAL_TOKEN` | 是 | MCP server ↔ 后端内部认证 |
| `DASHSCOPE_API_KEY` | 否* | 云模型密钥（*数据分级确认前不启用） |
| `ANYSEARCH_KEY` | 否* | 搜索密钥（缺省匿名 50 次/天；*分级确认前搜索关闭） |
| `DATA_CLASSIFICATION_CONFIRMED` | 是 | 数据分级授权清单签署后才可为 1 |
| `CLOUD_LLM_ENABLED` / `SEARCH_ENABLED` | 是 | 门禁：仅当上项=1 时可置 1，否则强制 0 |
| `STORAGE_ROOT` | 是 | `/data/appdata`（`/data` 为平台外挂持久卷） |
| `BACKUP_ROOT` | 是 | `/data/backups`（`/data` 为平台外挂持久卷） |
| `HTTP_PROXY` | 否 | 出站代理（搜索出网优先走代理） |
| `JWT_SECRET` | 是 | 令牌签名密钥 |
| `MAX_*_QUOTA` | 否 | 配额覆盖（默认见 4.11.1） |

## 3. 容器到手后的环境检查清单

- [ ] **持久卷**：容器内 `/data` 为平台外挂持久卷（约定），子目录 `pgdata/appdata/backups` 可写且容器重建后数据仍在（硬前提，无持久化则拒绝开工并升级部署形态）
- [ ] **资源**：内存 ≥4GB、磁盘 ≥50GB 可用（`free -m` / `df -h`）
- [ ] **网络**：出网策略（云模型/搜索域名是否可达；未确认分级前保持关闭即可）
- [ ] **密钥**：`local/container.env` 已填容器连接信息；`.env` 已填数据库/令牌/API key（两者均 gitignore）
- [ ] **端口**：容器内 8000（API）可被外部访问；8000 以外无需暴露
- [ ] **DNS/域名**：前端访问地址与后端 API 地址确认
- [ ] **时间**：时区 Asia/Shanghai，cron（备份）时区一致
- [ ] **GitHub 访问**：git push 可用（开发提交用）
- [ ] **部署**：按 `docs/部署安装手册.md` 执行 `deploy/install.sh`，`supervisorctl status` 全部 RUNNING
