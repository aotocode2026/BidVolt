# 数据分级与客户授权确认清单（P1 门禁）

> 用途：解锁云模型（DashScope / qwen-vl / LLM）与搜索（AnySearch）上线的**唯一前置确认**。
> 依据：Issue #1 P1「云模型和搜索服务在数据分级、客户授权、地域、留存、删除规则未确认前默认关闭」；后端架构设计文档 4.3/4.9/第 7 节。
> 规则：**未勾选项一律视为不同意**；L4 涉密数据任何情况下不发送云服务；本清单结论写入部署配置并记审计。

---

## 1. 数据分级定义（投标场景示例）

| 级别 | 定义 | 示例（本产品场景） | 是否允许出网 |
|---|---|---|---|
| L1 公开 | 公开发布、无保密要求 | 招标公告、公开标准、公开新闻 | 允许（脱敏后） |
| L2 内部 | 企业内使用、不宜公开 | 非敏感流程性资料、内部模板 | 需客户确认 |
| L3 敏感 | 泄露会对企业/客户造成损失 | 报价与成本、客户名单、人员证件、企业统一社会信用代码、检测报告、财务资料 | 默认禁止，逐项授权 |
| L4 涉密 | 法律/行业规定的重要数据 | 涉密项目、涉密资质、受控信息 | 禁止 |

> 待办：产品/客户可在本表基础上补充行业专属分级（如电力行业对电网数据的特殊要求）。

---

## 2. 客户授权项（逐项勾选）

- [x] **A1 云端 LLM**：允许将 L2 内部资料发送至云端 LLM（DashScope / qwen-vl）用于招标解析、标书生成/校核、模拟评标、针对性修改（产品已同意，2026-08-12）
- [ ] **A2 云端搜索**：允许将查询内容发送至 AnySearch 用于市场/政策/标准检索（出网前经 DLP 脱敏 + 域名白名单；开发期已启用匿名额度验证，正式签署待上线前完成）
- [ ] **A3 敏感数据**：允许将 L3 敏感数据（报价/成本/客户名单/人员证件等）发送至云服务（如需，须列明具体类别与用途）
- [ ] **A4 数据地域**：明确地域要求（如：仅中国大陆 / 指定地域），云服务商处理节点须满足该要求
- [ ] **A5 留存期限**：明确云端数据留存期限（建议：任务结束后 30 天内删除）
- [ ] **A6 删除规则**：明确删除规则与删除证明要求
- [ ] **A7 最小化**：同意云服务处理范围仅限本次任务所需（最小化原则）

## 3. 结论（三选一）

- [x] 解锁云模型（LLM / VL）+ 搜索（AnySearch）—— 产品已同意开发（2026-08-12）；开发期搜索走匿名额度，生产上线前完成 A2 正式签署 + 运维配置 Key
- [ ] 仅解锁云模型（搜索保持关闭）
- [ ] 均不解锁（全部本地化处理，云能力保持关闭）

## 4. 部署配置落点

```ini
# 部署配置（Secret Manager 注入，记审计）
DATA_CLASSIFICATION_CONFIRMED=1      # 本清单签署完成
CLOUD_LLM_ENABLED=1                  # 0 = 云端 LLM/VL 关闭（P1 门禁）
SEARCH_ENABLED=1                     # 0 = 搜索关闭（P1 门禁）
CLOUD_DATA_REGION=cn-east            # A4 地域要求
CLOUD_DATA_RETENTION_DAYS=30         # A5 留存期限
```

配置校验规则：`CLOUD_LLM_ENABLED`/`SEARCH_ENABLED` 只有在 `DATA_CLASSIFICATION_CONFIRMED=1` 时才能为 1；否则启动时强制置 0 并告警。
