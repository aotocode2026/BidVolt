# 部署安装手册（容器直接安装版）

> 服务器容器是**现成提供**的（不需要镜像构建）。本手册覆盖：本地记录连接信息 → 推送代码 → 容器内一键安装 → 验证 → 日常运维。
> 安全红线：`local/container.env` 与 `.env` **禁止上传 git**（已由根目录 `.gitignore` 排除）；密钥只进 Secret Manager 或容器环境变量。

---

## 1. 前置信息（拿到容器后填写）

把容器 IP、用户名、密码填入本地 `local/container.env`：

```ini
CONTAINER_HOST=<容器 IP>
CONTAINER_USER=<登录用户名>
CONTAINER_PASSWORD=<登录密码>
CONTAINER_SSH_PORT=22
CONTAINER_REPO_PATH=/opt/bidvolt
```

## 2. 本地准备

1. 复制 `.env.example` 为 `.env`，填入真实值：
   - `APP_DB_PASSWORD` / `DATABASE_URL`（数据库密码）
   - `JWT_SECRET`（>=32 位随机串）
   - `BIDVOLT_INTERNAL_TOKEN`（MCP 内部认证）
   - `DASHSCOPE_API_KEY` / `ANYSEARCH_KEY`（云模型/搜索；`DATA_CLASSIFICATION_CONFIRMED=0` 时保持关闭）
2. 提交并推送代码（`.env`、`local/` 已被 gitignore，不会误传）。

## 3. 连接与部署

```bash
# 本地：复制仓库与 .env 到容器（Windows 下用 scp/pscp，或先打包再传）
scp -r -P <port> . <user>@<host>:/opt/bidvolt
scp -P <port> .env <user>@<host>:/opt/bidvolt/.env

# 容器内：一键安装（apt 系统包 + Python venv + requirements + 初始化 PG/迁移 + 启动 supervisor）
ssh -p <port> <user>@<host>
cd /opt/bidvolt
bash deploy/install.sh
```

`install.sh` 自动完成：
1. apt 安装 PostgreSQL / ClamAV / LibreOffice / supervisor / cron / rclone 等
2. 创建 `.venv` 并 `pip install -r requirements.txt`
3. 在 `/data`（平台外挂持久卷）内准备子目录 `pgdata/appdata/backups`（卷本身由平台挂载，无需自建）
4. 安装 supervisor 配置与运维脚本
5. 初始化 PG 集群（空数据卷时）→ 建库/用户 → alembic 迁移 → 启动全部服务

## 4. 验证

```bash
# 容器内
bash /usr/local/bin/bidvolt-healthcheck   # 退出码 0 = PG + API 健康
curl http://127.0.0.1:8123/healthz        # 期望 {"status":"ok"}
supervisorctl status                      # postgres/app/worker/hermes/clamd/backup-cron 应全部 RUNNING
tail -f /var/log/bidvolt/supervisord.log
```

## 5. 日常运维

- **重启服务**：`supervisorctl restart app`（单模块）；`supervisorctl reload`（改配置后）
- **备份**：每日 02:00 cron 自动 `pg_dump` 到 `/data/backups`（保留 30 天）；恢复用 `pg_restore`
- **日志**：`/var/log/bidvolt/`（supervisord / backup / app 输出）
- **升级代码**：容器内 `git pull && .venv/bin/pip install -r requirements.txt && supervisorctl restart all`
- **数据安全**：`/data` 为平台外挂持久卷（约定），容器重建后数据仍在；`/data/pgdata`、`/data/appdata`、`/data/backups` 是唯一需要保留的目录

## 6. 安全说明

- `local/container.env`（容器连接信息）与 `.env`（API key/密码）**绝不提交 git**，由根目录 `.gitignore` 兜底
- 容器内的 `.env` 权限收紧：`chmod 600 /opt/bidvolt/.env`
- 云模型/搜索受 `DATA_CLASSIFICATION_CONFIRMED` 门禁控制（见 `.env.example` 与 `docs/数据分级与授权确认清单.md`）
- 连接容器尽量用 SSH key 替代密码；密码方案下注意传输通道安全（本手册 scp 走 SSH）
